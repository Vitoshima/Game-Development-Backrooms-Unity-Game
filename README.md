# Backrooms - Unity Horror Game

A first-person exploration horror game set in the Backrooms, built in Unity.

 **[Play it here](https://play.unity.com/en/games/eab09ab8-5b81-42f8-9cb7-15aff388ec07/backrooms)**

## About
A horror exploration game where you wander through liminal spaces, avoiding entities and trying to find your way out.

<img width="1917" height="1078" alt="image" src="https://github.com/user-attachments/assets/c6e6b6c2-d7b0-4885-9ed4-ed81959ee4a8" />




## Tech Stack
- Unity
- C#
- Universal Render Pipeline (URP)

## Controls
- WASD - Move
- Mouse - Look
- Shift - Sprint
- E - Interact

## Play
You can play the game directly in your browser on Unity Play:
